# Enki: Sanal Bebek (Android)

Konuşan, büyüyen ve arkadaşlarının bebekleriyle kamp ateşinde buluşan sanal bebek.

## İndir
**[Enki.apk (en son sürüm)](https://github.com/OzanCKN/enki-releases/releases/latest/download/Enki.apk)**

## Kurulum
1. Bağlantıyı Android telefonda aç ve dosyayı indir.
2. İndirilen `Enki.apk` dosyasına dokun.
3. Telefon "bilinmeyen uygulama" izni isterse, tarayıcıya veya Dosyalar uygulamasına izin ver.
4. **Yükle**'ye dokun.

Gereksinim: Android 8.0 veya üstü, 64 bit telefon, internet bağlantısı.

## Arkadaşınla oyna
**Arkadaşlar → Kamp ateşi yak**. Arkadaşın QR kodu okutur veya oda kodunu yazar, sonra bebeğini yukarı kaydırarak kamp ateşine fırlatır.
